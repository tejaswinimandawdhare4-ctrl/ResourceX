# ResourceX

Build a polished, modern, responsive B2B SaaS web application called:

RESOURCE X

Tagline:

B2B Hospitality Resource Exchange

IMPORTANT:

Use the uploaded ResourceX logo as the primary branding and visual reference.

Do NOT redesign, recreate, alter, or replace the logo.

The entire website should visually match the logo:

- Deep navy / midnight blue background

- Cyan / teal glowing accents

- White typography

- Thin cyan line-art / connection graphics

- Futuristic but professional technology aesthetic

The website is being built as a hackathon prototype for:

“HOSPITALITY RESOURCE EXCHANGE — SMART B2B MARKETPLACE FOR SHARED RESOURCES”

The website should look like a real startup SaaS product, NOT a generic AI-generated website.

==================================================

CORE CONCEPT

==================================================

ResourceX connects hospitality businesses that have underutilized resources with nearby businesses that temporarily need those resources.

Examples:

- Banquet spaces

- Parking spaces

- Furniture

- Tables and chairs

- Vehicles

- Kitchen capacity

- Audio-visual equipment

- Event equipment

- Hospitality resources

Providers can list and manage resources.

Seekers can:

- Search for resources

- Specify location, quantity, budget and date/time

- Compare providers

- View distance and availability

- Send booking requests

- Negotiate pricing

- Track request → booking → fulfillment

The central value proposition is:

“Connect unused hospitality capacity with businesses that need it.”
